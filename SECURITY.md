# Security policy

## Reporting a vulnerability

Report suspected security vulnerabilities through [GitHub private
vulnerability reporting](https://github.com/DG02002/mediapeek/security/advisories/new).

Do not open a public issue or discussion with exploit details. Include the
affected service or package, the relevant version or commit, reproduction
steps, security impact, and any suggested mitigation. Reports stay private
while they are investigated and disclosure is coordinated with the reporter.

## Supported versions

Security fixes are prioritized for the current `main` branch and the latest
stable release.
